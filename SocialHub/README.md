# SocialHub
This project is a social media web application built as part of my Front-End Development studies at Noroff. The goal of this application is to demonstrate my ability to consume a REST API, handle user authentication, and build a fully functional JavaScript application without the use of any front-end frameworks.

## Live Website
You can view the application here:
https://your-deployed-link.com
Features
Authentication

Register a new user account
Login with email and password
Secure token-based authentication using JWT and API Key

## Posts

View all posts in a feed
View a single post in detail
Create a new post
Edit your own posts
Delete your own posts
Search through posts using a search bar

##Profiles

View your own profile
View other users' profiles and their posts
Follow and unfollow other users

## Pages

Login page
Register page
Posts / Feed page
Single post page
User profile page

## API
This project uses the Noroff API v2.
Base URL : https://v2.api.noroff.dev
Authentication requires both a JWT Access Token and an API Key sent in the request headers for all protected endpoints.
